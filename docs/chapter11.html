11 从语法树到字节码：第一次真正生成程序 ​

学习目标与前置知识 ​

你已经能把源码读成 AST，并检查名字和类型。本章要把树变成一列可以检查、保存和执行的指令。完成后，你应能手工编译表达式、分支、循环和短路逻辑，检查每条路径上的栈是否平衡。前置是第 7、9、10 章的递归遍历、变量绑定和类型规则。

本章属于可运行主线：配套编译器确实包含字节码生成器和虚拟机。下面大写指令是教学记法，不是对实际输出格式的逐字复制；请用 sprout --bytecode 文件 查看真实指令。教学片段旨在推导算法，不能直接覆盖参考工程里的同名函数。

为什么不直接执行语法树 ​

AST 保留“这是乘法”“这是 while”等源语言结构。直接递归执行它也能构成解释器，但每次运行都需要访问节点类别和子节点。字节码提前把结构翻译成简单动作：读常数、取变量、算术、跳转、调用。执行器只需按照程序计数器逐条处理。

这里已经发生了编译：输入是 Sprout 程序，输出是另一套指令集的程序。VM 解释执行目标指令，并不否定前面的编译过程。以后换成 C++、LLVM IR 或本机指令时，词法、语法和语义前端仍可复用。第一台目标机器选择简单、容易观察的栈机，可以减少同时学习新概念的负担。

先设计计算栈 ​

栈是一叠只能从顶部取放的值。PUSH 压值；二元运算先弹右操作数、再弹左操作数，将结果压回。表达式 3 + 4 * 2 对应树的后序遍历：先左子树 3，再右子树乘法，最后加法。

text

PUSH 3      [3]
PUSH 4      [3, 4]
PUSH 2      [3, 4, 2]
MUL         [3, 8]
ADD         [11]

减法最能暴露操作数顺序问题：栈为 [8,2] 时 SUB 应得到 6。仅测加法与乘法不够，因为交换律会掩盖错误。除法和比较也必须保持同样的左右关系。

给每条指令写一份栈效果表：常数和 LOAD 净增一；STORE、PRINT 净减一；二元算术净减一；一元取负不改变高度。表达式编译前后的高度差应为一，普通语句应为零，return 把结果交回调用者。这组不变量可用于自动校验，比“样例能跑”更可靠。

用槽位代替名字 ​

前端已经区分了不同的变量绑定。参考实现的 Checker 在语义检查时给每个绑定分配一个整数槽位，代码生成器直接沿用，例如 main 的 x 是 0，内层块另一个 x 是 1。LOAD 0 读取当前函数帧的第 0 个槽位。生成器应使用前端解析出的绑定身份，不能再仅靠字符串重新查名，否则遮蔽关系容易丢失。

分支：先留空，再回填 ​

编译 if 时，生成条件后尚不知道 else 从哪个地址开始。先发出一个目标待定的跳转，记录它在数组中的位置；then 编译完后，回填目标。then 末尾还需无条件跳转，越过 else。

本清单约定条件跳转消费条件。若采用保留条件的指令设计，则两条路径都必须清理它；两种设计都可行，混用才会泄漏栈值。回填函数应接收明确的指令索引，而非修改“最后一条看起来像跳转的指令”，因为嵌套分支会使后者失效。

循环与短路都依赖控制流 ​

while 的生成顺序是：记录条件起点，生成条件与退出跳转，生成循环体，跳回条件，再回填退出位置。体结束时的栈高度必须等于进入体时，否则每轮会残留临时值。将上例替换为 let x=0; while (x<3) { print(x); x=x+1; } return 0;，预期依次输出 0、1、2。

短路不能简单翻译为“先计算左右，再 AND”。false && (1 / 0 == 0) 右侧根本不应执行。正确方向是左边为假直接产生 false，为真才进入右边。对于 ||，左边为真就跳过右边。汇合点上两条路径都必须留下一个 bool，且不能多留别的值。

下面是普通二元表达式的教学片段；短路表达式必须走专门分支：

cpp
void emitBinary(const BinaryExpr& expr) {
    emitExpr(*expr.left);
    emitExpr(*expr.right);
    emit(opcodeFor(expr.op));
}

常见错误与定位 ​

  • 循环只检查一次条件：回边指向体，应该指向条件起点。
  • then 结束后接着执行 else：缺少跳过 else 的跳转。
  • 循环越跑栈越长：语句没有消费临时值，或分支的栈效果不一致。
  • 嵌套块读错变量：代码生成丢掉了语义分析建立的绑定身份。

练习、答案与验收 ​

  1. 手工生成 (8-2)*(3+1) 并写每步栈内容。
  2. 画出 true || (1/0==0) 的两条路径。
  3. 将循环上界改为 0，再检查空循环行为。
参考答案

第一题依次为 PUSH 8、PUSH 2、SUB、PUSH 3、PUSH 1、ADD、MUL，最终为 24，最大栈高度 3。第二题左边 true 直接跳到得到 true 的路径，不能先执行除法再决定是否使用结果。第三题第一次条件即 false，应直接到循环之后。验收还需覆盖负数减法、嵌套分支和循环中的函数调用。
