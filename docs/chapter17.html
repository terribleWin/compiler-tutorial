17 本机代码生成：从无限名字到有限寄存器 ​

两条路线与学习目标 ​

本章将已实现的 C++ 目标路径与自行实现机器后端的扩展实验分开。前者用 --emit-cpp 生成独立 C++11 程序，再交给宿主编译器生成本机文件；后者才需要自己实现指令选择、寄存器分配、帧布局与机器约束。

两者都是编译路线。借用宿主后端不意味着前端没有完成编译，但也不能把它宣传成“已经自己写完 RISC-V 汇编后端”。本章目标是跑通真实本机路径，再手算一个最小机器后端。前置是第 11—16 章。

先跑通现成的目标路径 ​

以第 12 章的 fact 程序为输入，在 PowerShell 中使用 UTF-8 保存目标源码：

powershell
sprout --emit-cpp lesson12.sprout | Set-Content -Encoding utf8 program.cpp
g++ -std=c++11 -O2 program.cpp -o program.exe
.\program.exe
1
2
3

预期仍输出 24。类 Unix shell 可用 sprout --emit-cpp lesson12.sprout > program.cpp 并运行 ./program。目标代码需带检查型整数运行时、必要的函数声明和一致的求值顺序。用 VM 与本机程序比较打印和错误行为，是第 21 章差分测试的基础。

这里编译器本身与生成程序是两个不同对象：-std=c++11 可用于构建编译器，也可用于编译生成的目标。升级宿主编译器优化级别，不应改变 Sprout 语义。实际输出布局以生成文件为准，不需要期待它与某段手写 C++ 完全同形。

指令选择不是逐字翻译 ​

三地址 IR 的 t=add a,b 可映射为某台机器的 add，但立即数位数、操作数寄存器类别、结果位置都可能受限制。若常量能放进立即数字段，x+1 可使用 add-immediate；大常量则可能需要多条指令构造。

对树形表达式，可以用模式匹配：某种 IR 树匹配一种或几种机器指令，再比较代价。最简单的贪心从叶子生成；更高级的树覆盖用动态规划选择总代价较小的模式。DAG 中共享子表达式会使问题更复杂，因为重复展开可能增加计算。

代价也不只是指令条数：延迟、吞吐、代码大小、寄存器压力、目标微架构都可能不同。第一版后端先追求明确、可验证的映射，别从最优指令选择开始。

先把所有值放到栈上 ​

一个容易调试的最小后端可以给每个虚拟值分配栈槽，用少数临时寄存器完成 load、运算、store。它效率低，却能验证函数、分支、调用与 ABI。只有这条路线稳定后，再增加寄存器分配，否则地址计算和分配错误会混在一起。

检查型加法不能只发一条会回绕的 add 就结束。后端必须额外检测溢出，或调用一个明确实现语义的运行时函数。目标机器的默认行为不会自动等于 Sprout 规则。

活跃区间与线性扫描 ​

虚拟值数量可以无限，物理寄存器却有限。根据第 14 章活跃信息，把每个值从第一次到最后一次活跃的编号区间作为保守近似。区间可能覆盖实际上不活跃的洞，这会降低分配精度，但不应漏掉真实活跃点。

假设只有两个寄存器 R0、R1，区间采用闭区间：

值区间处理
A[1,4]分配 R0
B[2,6]分配 R1
C[3,9]无空闲，溢出 C 到栈
D[5,7]A 已结束，复用 R0

按起点排序，维护按终点排序的 active。新区间到来，先释放终点小于其起点的区间；若仍无空闲寄存器，比较新区间与 active 中最晚结束者，选择一个溢出。最晚结束启发式简单易实现，不保证在所有 CFG 上全局最优。

若约定改用半开区间，释放条件也要同步改变。许多“偶尔错”的分配器其实只是端点约定不一致，使同一时刻还需要的两个值占了同一寄存器。

溢出、调用与图着色 ​

溢出不是把值忘掉：为其分配栈槽，在使用前 reload，在定义后按需 store，还要避免溢出代码自己需要更多寄存器时形成无穷重写。第一版可预留专用临时寄存器，之后再优化。

函数调用会覆盖 caller-saved 寄存器。某值跨 call 活跃时，要放 callee-saved 寄存器，或在 call 前保存、后恢复。callees 使用保存寄存器时又有自己的保存义务。分配器必须把调用约束纳入模型，不能只看本函数的算术区间。

图着色方法把同时活跃的值连边，物理寄存器视为颜色，相邻节点不能同色。它能处理更细的干涉关系，但构图、溢出与合并更复杂。线性扫描与图着色是不同权衡，不是“简单算法一定没用、复杂算法一定更快”。

实验、练习与验收 ​

先为四个区间手算线性扫描，再把 C 的终点改成 5，观察启发式会改为溢出 B。画出这组区间的干涉图，尝试用两色着色。最后在本机生成路线中比较 -O0 与 -O2 的输出，确认正常程序语义一致。

参考答案

当 C=[3,5] 时，B=[2,6] 比 C 结束晚，可将 B 溢出、让 C 接用它的寄存器。C 与 A、B 在起点 3 都重叠，因此三个值形成三角形，两个寄存器无法同时容纳。验收包括区间端点、跨调用活跃值、参数多于寄存器数量、递归调用与溢出后的 reload/store，而不仅是直线加法。
