# 第04章 先设计一门说得清楚的语言

## 本章目标与前置

你已经能够构建参考工具。本章要把“好像能运行”变成“根据规则就知道应该发生什么”。学完后，你应该能读懂一份小型 EBNF 文法，为 Sprout 写正常程序，也能区分词法规则、语法规则、静态语义与运行时语义。配套 `compiler/SPEC.md` 是实现的精确契约；本章给出教学主线，边界行为以该文件和测试共同核对。

## 4.1 为什么不能边写代码边猜规则

考虑 `1 + true`、`x = x + 1`、`if (3)`。不同语言可以给它们完全不同的含义。若没有规范，扫描器、类型检查器和虚拟机可能各自做出不同选择：某一层把布尔当整数，另一层却禁止混算。这类矛盾很难靠增加补丁修复。

我们先选择一门小而完整的语言。Sprout 的主线有整数、布尔、局部变量、赋值、分支、循环、函数和递归。整个程序由函数定义组成，要求存在无参数、返回整数的 `main`。简单语句以分号结束，条件使用圆括号，语句体使用花括号。明确的边界能让第一台编译器保持可理解，同时支持有意义的程序。

## 4.2 字符、名字与字面量

教学主线采用 ASCII 标识符：第一个字符是英文字母或下划线，后续可以继续出现字母、下划线和数字。`total2` 是一个名字，`2total` 不能作为一个名字。大小写有区别，`Total` 和 `total` 是不同名字。中文解释可以写在注释中；这不意味着中文自动成为合法标识符。

数字采用十进制整数，前导0仍按十进制处理。负数由一元负号与表达式组合得到，所以 `-3` 的结构与单纯的数字字符序列不同。整数范围是 `-2147483648` 到 `2147483647`。最小负值的字面量解析有特殊边界问题：正数字符串 `2147483648` 已超过正范围。参考实现允许直接写 `-2147483648`，但单独写 `2147483648` 会被拒绝；也可以使用 `-2147483647 - 1` 表达最小值。

词法阶段仍将负号与数字分开。参考 Parser 在负号直接跟数字时，将两者合为一个带符号 Number 节点，所以 `--ast` 中 `-3` 可以显示为单个负整数；`-x` 则保留一元节点。这是表示方式的选择，不改变运算优先级。`-(2147483648)` 中的正字面量依然无效。

`true` 和 `false` 是布尔字面量。`fn`、`let`、`if`、`else`、`while`、`return` 等关键字不能随意当变量名。空格、制表符、换行分隔单词，但通常不改变表达式意义。`//` 开始的注释持续到行尾；不要自行假设还支持 `/* ... */`。

## 4.3 用 EBNF 表示语法

文法描述“允许怎样排列”，不负责证明变量已经声明。双引号表示必须出现的符号；`{ X }` 表示 X 重复零次或多次；`[ X ]` 表示可选；`|` 表示选择。下面是主线语法的教学表示，辅助规则在下一节补全：

```ebnf
program    = { function } EOF ;
function   = "fn" IDENT "(" [ parameters ] ")" "->" type block ;
parameters = parameter { "," parameter } ;
parameter  = IDENT ":" type ;
type       = "int" | "bool" ;
block      = "{" { statement } "}" ;
statement  = "let" IDENT "=" expression ";"
           | IDENT "=" expression ";"
           | "print" "(" expression ")" ";"
           | "return" expression ";"
           | "if" "(" expression ")" block [ "else" block ]
           | "while" "(" expression ")" block
           | block
           | expression ";" ;
```

独立的块语句可以创建更内层的作用域；表达式语句可以调用函数并丢弃它的返回值。赋值只作为语句存在，因此 `x = y = 1;` 不属于这门语言。`let` 不支持显式类型标注；`else` 后必须跟块，不能直接使用 `else if` 简写。需要继续嵌套时写成 `else { if (...) { ... } }`。

非终结符 `expression` 代表“这里还需要展开表达式规则”，终结符 `"let"` 则代表真实输入中的关键字。把 `IDENT` 当成 Token 种类，而不是要求用户真的敲出五个字母 `IDENT`。

## 4.4 表达式分层就是优先级

```ebnf
expression = logical_or ;
logical_or = logical_and { "||" logical_and } ;
logical_and = equality { "&&" equality } ;
equality   = comparison { ("==" | "!=") comparison } ;
comparison = addition { ("<" | "<=" | ">" | ">=") addition } ;
addition   = multiply { ("+" | "-") multiply } ;
multiply   = unary { ("*" | "/" | "%") unary } ;
unary      = ("!" | "-") unary | primary ;
primary    = INTEGER | "true" | "false" | IDENT
           | IDENT "(" [ arguments ] ")"
           | "(" expression ")" ;
arguments  = expression { "," expression } ;
```

层次越靠下，结合越紧。`1 + 2 * 3` 的加法右侧要先读完整个乘法层，所以乘法成为子树。重复规则对应左结合：`8 - 3 - 1` 表示 `(8 - 3) - 1`，结果是4。比较的语法可以容许重复出现，但类型规则通常会拒绝 `1 < 2 < 3`：第一次比较产生布尔，不能继续与整数3进行整数大小比较。语法可解析与语义合法不是同义词。

逻辑运算具有短路行为。`false && right` 不计算右侧，`true || right` 也不计算右侧。它决定了哪些运行时错误会真正发生，不能只当作节约计算时间的可选优化。

## 4.5 静态规则是第二层约束

变量声明 `let x = expression;` 从初始化表达式推断变量类型，之后类型固定。赋值必须使用相同类型。`if`、`while` 的条件必须是布尔，不把整数0和1隐式当作条件。算术和大小比较作用于整数；逻辑运算作用于布尔；相等比较的两端需要匹配类型。

函数的参数与返回值有明确类型。调用前检查函数是否存在、实参数量是否一致、每个实参类型是否匹配。编译器先收集所有函数签名，再检查函数体，因此可以支持先调用后定义，以及递归。函数不是一等值，不能假设可以将函数名存入变量或在函数内部定义函数。

局部变量采用词法作用域：名字绑定由源程序的嵌套结构决定。进入内层块，建立新的局部环境；离开时恢复外层环境。我们不提供全局可变变量、指针和隐式类型转换，使前端规则能在初学阶段完整解释。

## 4.6 一个有意义的程序

```sprout
fn fib(n: int) -> int {
    if (n < 2) {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

fn main() -> int {
    let i = 0;
    while (i < 8) {
        print(fib(i));
        i = i + 1;
    }
    return 0;
}
```

预期输出依次是 `0`、`1`、`1`、`2`、`3`、`5`、`8`、`13`，各占一行。`i < 8` 给出布尔条件，`i = i + 1` 改变当前调用中的局部变量。每次调用 `fib` 都有自己的参数 `n`，递归不是让所有调用共享一个全局的 `n`。

这个例子的递归算法适合展示调用机制，不适合计算很大的斐波那契数。重复子问题会使运行时间迅速增长，而且32位整数会溢出。算法效率、整数范围和语言语义是三个分别需要思考的问题。

## 4.7 把运行时也写进规范

整数溢出、除零和非法的最小负数取负都要报告错误。求值顺序、短路行为、参数传递和打印格式也要明确。当前实现设置执行资源限制，避免无限循环或过深递归拖住教学工具。资源限制是实现保护条件，不等于证明所有程序都会终止。

不要把 C++ 中恰好发生的行为直接继承给 Sprout。例如 C++ 某些求值顺序细节随版本变化，我们的两个后端仍然应该实现同一套 Sprout 规则。后续会用差分测试检查这件事。

## 4.8 练习与验收

练习一：按文法解释为什么 `let x = 3;` 不能直接放在文件最外层。

<details>
<summary>查看答案</summary>

`program` 只重复 `function`，而 `let` 语句只通过函数体中的 `block` 进入语法。文法没有允许顶层声明这条路径。可以把它放进 `main` 的函数体。

</details>

练习二：`if (1) { print(2); }` 是词法错误、语法错误还是类型错误？

<details>
<summary>查看答案</summary>

每个字符能分词，数字也是合法表达式，所以语法能够建立树。但条件表达式类型是整数，违反条件必须为布尔的静态规则，属于类型错误。

</details>

练习三：给语言增加数组前，至少需要补充哪三类约定？

<details>
<summary>查看答案</summary>

至少要定义数组构造与下标访问语法、元素与数组的类型规则、分配及越界访问的运行时规则。若允许赋值或传参，还需要说明复制还是共享存储。只增加一对方括号远远不够。

</details>
