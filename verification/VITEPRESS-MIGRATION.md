# VitePress 统一排版与品牌验证

日期：2026-11-06。本记录对应当前网页，首次交付的编译器和课程验证记录继续保留。

## 改动

- 整站采用 VitePress 1.6.4 默认文档主题，统一蓝色品牌、目录、标题、表格和代码块。
- 桌面正文18px，手机17px，正文行高1.9；代码约14px，GitHub 风格深浅高亮、原生复制与行号，补充换行、折叠、放大和行号切换。
- 新增 Sprout 原创矢量 Logo：编译角括号包围分支新芽，提供主图形、单色版、favicon、深浅组合版和透明512px PNG。
- 原有表达式与张量实验迁移为 Vue 组件，支持站内无刷新切换；学习进度沿用原本的 `sprout-progress` 浏览器记录。
- 所有 `content/` 正文和 `compiler/` 文件与改版前一致，已用 Git 差异检查确认。原有章节网址保持不变。

## 实际验证

生产构建通过。38个页面、25章、2306个站内资源链接、411个锚点、124个带行号代码块和18文件源码ZIP检查通过，详见 `vitepress-static-results.json`。

Edge/Chromium 桌面1440×1000和手机390×844的71项浏览器检查通过，无未捕获的页面错误和资源加载失败，详见 `vitepress-browser-results.json`。

检查覆盖正文实际字号、品牌SVG、中文与英文搜索、原有学习进度迁移、主题保存、代码精确复制、换行后的行号对齐、折叠/放大/Escape、两个实验的计算与错误边界、SPA往返不重复绑定、手机目录开关与整页溢出、源码下载。已视觉查看首页、代码、暗色和手机排版截图。

## 可复现构建

Node.js 22+、Python 3，执行 `npm ci`、`npm run build`、`npm run check`。VitePress 正式版保持1.6.4，构建依赖锁定修复版 Vite 6.4.5，生产构建和浏览器检查使用该组合；安装后的 npm 依赖审计为0项。

源码与工具链的行为没有改变，因此没有重新编写编译器测试；GitHub 的既有四标准构建和行为验证继续运行。
