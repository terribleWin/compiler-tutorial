# Sprout 品牌标志

品牌名称为 **Sprout / 从零造编译器**。Sprout 表示从小程序逐渐长成完整语言；标志左右是编译语境中的角括号，中间的新芽由分支、主干与输出节点构成，连接“代码结构”和“循序成长”两个意象。

## 文件

| 文件 | 用途 |
| --- | --- |
| `logo-mark.svg` | 主图形，用于网站导航、首页与分享素材 |
| `logo-lockup.svg` | 英文与中文组合，适用于浅色背景 |
| `logo-lockup-dark.svg` | 同一组合的浅色文字版，适用于深色背景 |
| `logo-mark-mono.svg` | 单色版本，适合打印、印章或单色背景 |
| `favicon.svg` | 简化小尺寸图形，用于浏览器标签页 |

均为原创、可缩放 SVG，不依赖位图或外部字体服务。组合标志的文字采用常见系统字体回退；如需用于印刷，可在矢量编辑器中将文字转成轮廓后导出。

主色为编译蓝 `#496BF0` / `#3154CE`，辅助色为新芽青 `#38C9C3` / `#148FA5`。单色版为 `#3B5BD6`。建议标志四周保留至少图形宽度 1/8 的空白；主图形建议不小于 24 px，16 px 标签页使用专门的 favicon 版本。深色环境保持原图颜色，不添加黑色描边。
